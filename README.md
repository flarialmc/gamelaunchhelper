# Game Launch Helper

> [!IMPORTANT]
> - The fork is licensed under [**`GPLv3`**](https://choosealicense.com/licenses/gpl-3.0/).
> - The fork is tailored towards Flarial.

- Replaces [PC Bootstrapper](https://learn.microsoft.com/gaming/gdk/docs/gdk-dev/pc-dev/overviews/gr-pc-bootstrapper) provided by Gaming Runtime Services.
- To install this, simply install a game version via [Flarial Client's launcher](https://github.com/flarialmc/Flarial.Launcher).
